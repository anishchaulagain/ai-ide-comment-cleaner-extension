# Change Log

All notable changes to the "Smart Comment Remover" extension will be documented in this file.

## [1.1.0] - 2024-02-15
- Integrated OpenAI API as the primary AI service for comment analysis.
- Added Groq API integration as a fallback service when OpenAI is unavailable.
- Implemented robust error handling and API key management via environment variables.

## [1.0.0] - initial release
- Initial release of AI-Powered Comment Remover.
- Support for 15+ languages.
- Intelligent preservation of docs, licenses, and pragmas.
- Workspace batch processing.
- Diff preview functionality.
